Build a Next.js app with MapLibre GL JS that:
- Displays a map centered on New York State
- Has a base map toggle (streets / satellite / terrain using free tile sources)
- Loads NYS county boundaries from a GeoJSON file and displays them as a colored layer
- Has a species dropdown (mock list of 5 bird names)
